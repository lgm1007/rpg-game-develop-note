## 공통 개발 환경 · 원칙

- Unity 6000.6.2f1 / URP 2D / Input System / C# 9, macOS (Apple Silicon)
- **외부 이미지 에셋 없이 모든 그림을 코드로 생성** (캐릭터·몬스터·월드·아이콘·UI). 글꼴만 라이선스가 확인된 나눔스퀘어라운드(SIL OFL)를 넣었다 (09)
- 게임 규칙은 UnityEngine 을 쓰지 않는 **순수 C# Core 어셈블리** 에 두고(서버 이식 대비), Unity 쪽은 입력·연출만
- 세이브 스키마가 바뀌면 `SaveData.CurrentVersion` 을 올리고 마이그레이션 단계를 추가 (현재 v6)
- 검증: Unity batchmode EditMode 테스트 (에디터가 열려 있으면 프로젝트 복제본에서), 그림은 dotnet 미리보기 도구 / 에디터 캡처 스크립트로 확인

## 개발 중 쓰는 도구

| 도구 | 용도 |
|---|---|
| Unity batchmode `-runTests` | 컴파일 + EditMode 테스트 (161개, 12 기준) |
| 프로젝트 복제본 (APFS `cp -c`) | 에디터를 켜 둔 채로 batchmode 테스트·캡처를 돌리는 사본 (용량 추가 없음, 캡처 전용 코드는 사본에만) |
| dotnet 그림 미리보기 도구 | 캐릭터·몬스터·월드·아이콘 그리기 코드를 Unity 없이 4초 만에 PNG 로 렌더 (지역별 몬스터 줄 세우기, 4방향·동작 시트) |
| 밸런스 계산 콘솔 (임시) | 게임 규칙(Core) 코드를 dotnet 으로 돌려 레벨별 몬스터 능력치 · 몇 대에 잡히나 · 레벨업까지 사냥 수를 표로 뽑음 |
| 맵 설계 스크립트 (임시) | 타원 호수 · 굽은 길 · 숲 무리 · 바위 턱 · 골짜기를 칠해 ASCII 맵을 만들고, 줄 길이 · 연결성(스폰에서 포탈 · NPC · 사냥터까지, 갇힌 틈 메우기) · 길 앞을 가리는 나무를 검사 |
| 맵 전체 미리보기 (임시) | 바닥 · 장식물 · 포탈 · NPC · 몬스터 자리를 맵 한 장으로 같은 축척에 그려 필드끼리 크기 · 지형을 비교 (한글 이름표는 macOS 의 Swift 로 붙인다) |
| 에디터 캡처 스크립트 (임시) | batchmode 에서 GameSession 을 조립해 실제 HUD·월드 화면을 PNG 로 찍음 (게임 저장소에는 넣지 않음) |
| 에디터 시뮬레이션 스크립트 (임시) | 플레이어 로직을 프레임 단위로 돌려 NPC 대화·스킬 뒤 자동 공격·스킬 시전 흐름 검증 |
| batchmode Play 모드 흐름 시험 (임시) | 복제본을 실제 Play 모드로 돌려 선택창 → 캐릭터 만들기 → 게임 → 선택창 → 다른 캐릭터 흐름, 보스 안내 → 입장 → 큰 공격 → 처치 흐름, 전직 퀘스트 대화, 모든 보스 큰 공격 발동, 상점 창(사기 · 탭 · 스크롤 · 멀어지면 닫힘)을 단계마다 확인 (세이브는 임시 폴더) |
| 비교 페이지 + 헤드리스 크롬 (임시) | 글꼴 후보를 실제 게임 문구로, UI 방향을 목업으로 한 장에 그려 PNG 로 찍어 고르는 데 씀 |
| 글꼴 글자 표 검사 (임시 스크립트) | 글꼴 파일의 글자 표(cmap)를 읽어 게임 코드에 쓰인 글자가 모두 있는지 확인 |
